# FROM ANDREW CODESMITH
## How to think about DSA
1. Rather than practice makes perfect, "practice makes GOOD".
2. A good mindset shift is actually quite fun. Look at it as a beautiful thing like puzzle and have fun.
3. Use whatever language you are good at! (python, java or javascript)

## Where to start
1. Learn high level concepts of all the different topics:
What is a data structure, what are the different algorithms (recurrsion, pointers). Just learn at high level.
2. You have to Nail down Big O (both time complexity and space complexity). Be able to look at your code and figure out the Big O notation

## How to Practice
1. Start writing Data Structure out from scratch. Lean into the idea of memorising them. Write it so many times that it becomes second nature. Build them from scratch and dont be scared of memorising them.
2. Start doing leetcode. If you start leetcode and find the easy problems as so hard, then check <b>CODEWARS</b>. Codewars is quite beginner friendly. These problem training the logical part of your brain. Try and keep it fun.
3. So start every coding session (like maybe when you are about to work on a project), start with solving a problem on codwars or leetcode.
4. Use chatgpt, give it problems, ask it how it can make it more performant.
